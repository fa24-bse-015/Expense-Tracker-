# SpendWise - Personal Expense Tracker

A lightweight, responsive frontend single-page application built with React, Vite, and Tailwind CSS to log, categorize, and track personal expenses.

## Tech Stack & Choices
- **React (Vite):** Chosen for optimal development speed, component-driven structure, and clean state management.
- **Tailwind CSS (v4):** Used for rapid and responsive utility-first styling without bloating the codebase.
- **LocalStorage API:** Utilized to persist expense data natively on the client side between browser reloads.

## Features Built (Core Requirements)
- Full Create / Edit / Delete flow for expenses.
- Each expense tracks Amount, Category, and Date.
- Combined filtering by Category and Date Ranges.
- Summary dashboard displaying total spent and category-wise breakdowns.
- Clean inline form validation logic.
- Fully responsive mobile-first UI layout.
